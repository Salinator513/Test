# Branch B001 — Current Accepted State

## Research objective
Under a fixed inference-compute budget, which design features of a role-separated multi-agent research loop most reduce unsupported claims and cumulative reasoning errors compared with repeated single-agent prompting?

## Accepted factual record
No accepted external evidence yet.

## Current claims

## Current hypotheses
- Role separation may reduce some classes of cumulative error by limiting each invocation’s objective and context, but this is unverified.
- Externalized memory and explicit provenance may matter more than the number of agents, but this is unverified.

## Known objections
- Multiple agents using the same underlying model may create correlated rather than independent judgments.
- Added roles may increase cost and error propagation without improving accuracy.
- Apparent gains may come from additional compute rather than role separation itself.

## Unresolved questions
- Which design elements have direct empirical support?
- How should a fixed-compute comparison be constructed?
- Which failure modes can role separation plausibly reduce?
- Which roles create unique value rather than duplicated effort?
