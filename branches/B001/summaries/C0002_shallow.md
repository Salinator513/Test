# C0002 Shallow Summary

## Frontier investigated

C0002 examined whether the proposed persistent-versus-fresh comparison can be made interpretable by controlling prior-trace access and transferred state. The cycle corrected the frontier from an undefined “fresh boundary” to observable factors: trace access, package representation, retention, dependency preservation, compression, salience, retrieval, and compute allocation.

## Most important evidence

The fourteen-source ledger found no noncollapsed package-only persistent-versus-package-only fresh study with matched visible inputs, no prior-trace access, matched tools and sampling, and full compute. `C0002-SRC-01` most directly supports an information-access and relay-fidelity framing: bounded relays can help or harm according to what information survives. Other sources report prior-history interference, context-position effects, write-time evidence loss, and persistent difficulty preserving temporal or causal dependencies.

## Main state change

The branch now accepts a qualified information-filtering tradeoff rather than an intrinsic fresh-container effect. Scalar “state completeness” is rejected; future work must separately measure schema compliance, item retention, dependency and relation preservation, package transformations, write and retrieval loss, and information geometry.

## Strongest unresolved objection

After trace access and visible inputs are matched, no nontrivial residual difference between package-only persistent and fresh execution has been defined. A null comparison may therefore represent treatment collapse rather than a zero effect.

## Current direction

Define a canonical typed package and dependency inventory, then preregister a three-condition access decomposition, exact-package replay, coverage-sensitive lineage scoring, manipulation checks, and a full compute and saved-budget rule.
