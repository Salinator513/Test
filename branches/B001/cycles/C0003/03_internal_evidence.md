## Prior Contradictions or Objections

1. **Metadata availability versus representation:** `branches/B001/cycles/C0003/02_critic.md`, Fatal Problem 1, establishes that explicit links add information absent from a flat list. Relation-present versus relation-absent estimates metadata availability, not a pure representation effect. A representation test must encode approximately the same relation content in both conditions.
2. **Bundled estimands:** The C0003 Explorer combines relation links, status labels, package minimality, writer quality, geometry, reader capability, retrieval, unresolved questions, and task interactions. The Critic requires one metadata type and one primary estimand.
3. **Reference-package privilege:** A reference package can add corrected content, evaluator judgment, validation labor, or downstream-informed choices. It can serve only as a predeclared diagnostic upper bound unless construction inputs, timing, validation, and cost are controlled.
4. **Exact replay versus retrieval:** Byte identity only removes writer variation. It does not prove equal effective access, retrieval, or use. Retrieval must be exposed as an observed selection object.
5. **Write dominance versus unobserved lineage:** Existing branch artifacts were not generated under matched counterfactual packages. They cannot establish the prevalence or dominance of write-stage failure.
6. **Length matching versus second interventions:** Deleting relation content, adding filler, or changing order to equalize tokens can alter information density, salience, and retrieval competition.
7. **More context versus usable context:** `current_state.md` preserves the contradiction that full trace may retain evidence while reducing salience, whereas concise packages may improve usability while deleting dependencies.
8. **Compression efficiency versus interface loss:** C0002 stores both possible condensation gains and relay/write losses. No monotonic compression effect is accepted.
9. **Traceability versus support:** Claim IDs, citations, and provenance links improve traceability but do not establish correct or complete support.
10. **Semantic similarity versus epistemic preservation:** Similar wording can conceal changed status, scope, qualification, support, contradiction, or uncertainty.
11. **Null result versus treatment collapse:** Package equality can reflect a true null, no distinct manipulation, weak annotations, insensitive tasks, opposing subgroup effects, or unreliable measurement.

## Internal Evidence Gaps

The branch contains **no internal causal evidence** that explicit claim–support links, qualification links, status labels, contradiction links, dependency links, or unresolved-question links improve downstream accuracy, support, coverage, or lineage under matched conditions.

The branch also contains no internal evidence that:

- typed edges outperform equivalent controlled prose;
- package writing is the dominant bottleneck;
- any one stage transition is especially sensitive to reset or trace restriction;
- a minimal package size or universal sufficient schema exists;
- unresolved-question continuity independently reduces premature closure;
- exact replay yields equal effective access across readers;
- prior-cycle defect examples estimate causal prevalence;
- a package hash, retrieval checkpoint, and lineage codebook have been implemented and validated;
- annotation reliability, evaluator bias, minimum coverage, or task-density thresholds meet any accepted standard;
- package and validation overhead can be matched under an accepted end-to-end budget rule.

A branch-local apparatus is still missing. At minimum it would need: a schema and version; canonical serialization; a predeclared claim and relation inventory; package bytes and cryptographic hash; writer input and output records; independent validation record; reader prompt and surrounding-context records; prior-trace, model, setting, tool, candidate, selector, and integration declarations; an explicit retrieved or selected subset; final claims; a claim-lineage map; and a complete resource ledger.

A defensible **candidate pilot**, not an accepted design conclusion, is the `C0003` Explorer-to-Critic transition using one relation type only: claim-to-support/limitation. A small predeclared inventory could contain `C0003-EXP-01`, its explicit limitation that no effect is accepted, `C0002-INTG-03`, `C0002-INTG-04`, and the Critic’s Fatal Problem 1 objection. This inventory includes an accepted derived conclusion, an accepted methodological requirement, a current hypothesis, a qualification, and an objection. It is suitable for apparatus testing, but existing artifacts do not provide a matched counterfactual package or causal estimate.

## Questions Requiring External Evidence

1. Are there controlled primary studies that vary one explicit metadata type—preferably claim–support or qualification metadata—while holding base claim content and downstream task approximately constant?
2. Are there primary studies comparing equivalent relational content expressed in controlled prose versus typed fields, tables, graphs, or links?
3. Are there validated methods that separately observe package writing, explicit retrieval or selection, and downstream use using predeclared inventories, controlled corruption, reference packages, or exact replay?
4. Are there claim-lineage or epistemic-transition annotation schemes with reported reliability for omission, retyping, qualification change, contradiction, correction, mutation, and amplification?
5. Are there controlled information-geometry studies that can function as confound checks for metadata experiments rather than as evidence for metadata effects?
6. Do direct studies report enough end-to-end cost and component detail to separate metadata availability, representation, writer or validator effort, retrieval tools, extra calls, candidate generation, selectors, and final integration?
7. Do any studies implement these contrasts in open-ended multi-source research synthesis rather than memory QA, short-answer reasoning, summarization, navigation, or agentic benchmarks?
8. Which candidate studies reuse C0002 sources, benchmark families, or mechanism families and therefore must be labeled as prior branch evidence rather than new independent confirmation?

## Handoff to External Evidence Researcher

Search narrowly for evidence direct to the corrected estimand. Prioritize one metadata type and keep two contrasts separate:

1. **Metadata availability:** identical base claims, relation absent versus explicitly available.
2. **Metadata representation:** approximately equivalent relation content in controlled prose versus a typed field or edge.

For every candidate source, record the manipulated factor, whether base semantic content is matched, whether the reference inventory and relations are predeclared, whether retrieval or selection is observed, whether downstream use is traced, whether coverage and task completion are protected, and whether end-to-end resource costs are reported. Treat broad structured-memory, graph-memory, condensation, write-memory, and long-context studies already represented in C0002 as mechanism background unless they directly implement the corrected contrast. Do not count reused benchmarks, source families, or same-model reinterpretation as independent evidence.
