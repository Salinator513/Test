# Internal Evidence Researcher — C0006

## Current Research Questions

1. What exact later decision would a successful measurability audit authorize, what claim scope would it support, and what task population or Alternative Theorist stratum would it cover?
2. Which denominator objects are distinct and non-nested at the External Evidence Researcher → Alternative Theorist handoff: task instances, role outputs, sections, role-function units, upstream factual units, evidence units, candidate-relation sets, relation edges, bounded relation groups, eligible primary units, downstream units, lineage links, and clusters?
3. Which objects are directly recoverable from ordinary authorized artifacts, which require offline annotation only, and which require new reporting, retrieval, selection, or rationale checkpoints that change behavior or cost?
4. What protocol-grounded multilabel taxonomy separates assertive factual claims and improper factual promotions from source interpretations, derived conclusions, hypotheses, speculation, objections, hybrids, and unresolved questions?
5. Which numerator/denominator ratios are valid because their objects are nested or linked by a frozen mapping rule, and which proposed ratios would mix incompatible object types?
6. How should duplicate, complementary, substitutable, repeated, split, merged, overlapping, and many-to-many support structures be counted without either pair inflation or erasure of real multiplicity?
7. How can role relevance be represented through observable role functions and blinded importance judgments without inferring latent dependence or later treatment benefit?
8. Which parts of the denominator-and-observability system are already constrained by accepted branch state, and which remain new design choices requiring methodological support and later validation?

### Branch-Grounded Denominator and Observability Map

**Status:** Derived internal synthesis from the accepted items above and the C0006 Critic brief. It is not an accepted branch claim and contains no prevalence estimate.

| Object type | Ordinary-artifact observability | Minimum prospective fields | Identity and mapping constraint |
|---|---|---|---|
| Task or prompt instance | Coarsely inferable from cycle/role artifacts, but no canonical object exists | task ID, prompt/version, corpus stratum, intended population | Parent of one or more role outputs; must be frozen before sampling claims |
| Role output | Directly present as a role file | task ID, role, cycle, file/version, completion status | One file/output can contain several sections and role functions; raw current-cycle content is not accepted state |
| Output section | Markdown sections are directly visible; semantic sections may require annotation | output ID, section ID, heading/span | Sections may contain several role functions and are not interchangeable with claims |
| Role-function unit | Requires offline annotation; no new agent behavior is inherently required | unit span, multilabel function, factual-assertion flag, improper-promotion flag | Mixed units require splitting or multilabel coding; taxonomy must be frozen and reliability tested |
| Upstream factual unit | Usually requires offline atomic-claim annotation | claim ID, text/span, epistemic type, scope, qualification, source-attribution status | May split/merge across wording; must map to role-function units without assuming one sentence = one claim |
| Evidence unit | Source IDs/locators may be visible, but adjudicable content units and context usually require annotation and sometimes full-source access | evidence ID, source ID, locator, excerpt/span, context sufficiency, multi-span membership | One evidence unit may support several claims; locators alone are not always sufficient |
| Writer-supplied relation set | Observable only when explicit links are written | relation-set ID, generation procedure, source access, listed claim/evidence IDs | Bounded to supplied links; not the universe of all true or possible relations |
| Coder-proposed relation set | Requires offline coder generation under fixed access | coder/procedure, bounded evidence set, candidate IDs, access rules | A different candidate universe from writer-supplied links; must not be pooled without labeling |
| Checkpoint-reported relation or selected set | Requires new agent reporting and is intervention-created | checkpoint timing, candidates, selected IDs, rationale fields if any, cost | Records reported selection only; changes ordinary behavior and cannot measure natural latent retrieval |
| Relation edge | Requires explicit link or offline annotation | edge ID, claim ID, evidence ID, relation class, polarity, scope/qualification fit | Multiple edges may be duplicate, complementary, substitutable, or genuinely distinct |
| Bounded relation group | Requires new grouping rules and offline annotation | group ID, member edges, group semantics, support-composition type | Non-nested with sections/sources in general; group counts must remain visible beside edge counts |
| Eligible primary unit | Annotation-created after frozen codebook | upstream claim, evidence unit, direct-support judgment, scope/qualification, downstream unit | Only a prospectively eligible subset; exclusions must be logged and cannot define the denominator post hoc |
| Downstream output unit | Requires offline segmentation/annotation | downstream ID, text/span, role function, factuality, epistemic status | May merge or split upstream material; is not necessarily one-to-one with upstream claims |
| Observable lineage link | Requires offline comparison unless explicit IDs are carried | upstream/downstream IDs; content, attribution, scope, qualification, polarity, status, split/merge, contradiction, extension fields | Establishes observable correspondence only, not causal dependence |
| Source, passage, claim-family, output, or task cluster | Requires frozen clustering and identity rules | cluster type, cluster ID, member IDs, rule | Different cluster types represent different dependence structures; the primary cluster must follow the intended inferential target |
| Exclusion record | Requires offline annotation under a frozen ledger | candidate/object ID, multilabel reason, affected role function, qualification burden, source structure, checkpoint dependence | Every excluded candidate in the bounded universe must remain auditable; exclusion is not absence of workload |

### Allowed-Ratio Constraints

**Status:** Derived internal synthesis; not yet validated.

| Measure | Potentially valid form | Required constraint |
|---|---|---|
| Factual-stratum share | factual/assertive role-function units ÷ all role-function units | Same frozen unit taxonomy and sampling frame; report multilabel treatment |
| Eligible factual coverage | unique eligible upstream factual units ÷ all upstream factual units in the predeclared factual stratum | Same atomicity rules; deduplicate before division; preserve excluded reasons |
| Edge eligibility rate | eligible relation edges ÷ candidate edges in one explicitly named generation universe | Candidate universe and source access must be fixed; never label it all possible true relations |
| Group eligibility rate | eligible bounded relation groups ÷ all bounded groups in the same generation universe | Group semantics and edge-to-group mapping must be frozen |
| Downstream factual-unit coverage | downstream factual units with observable relation-preserving incorporation ÷ all downstream factual units in the sampled output scope | Same downstream segmentation and role-function rules; no causal-dependence wording |
| Qualification coverage | qualification-bearing units whose qualifications are observably preserved ÷ qualification-bearing units in the named upstream or downstream scope | The numerator and denominator must use the same qualification object and mapping direction |
| Role-function coverage | represented units within each predeclared role-function stratum ÷ all units in that same stratum | Report by stratum; do not generalize a factual-stratum result to the whole role |
| Source or cluster diversity | unique clusters represented among eligible units, reported with the underlying unit count | Diagnostic only unless a sampling model and population are declared |
| Edge-to-group count ratio | relation edges ÷ bounded relation groups | Sensitivity diagnostic, not evidence that extra edges are inflation |
| Weighted substantive coverage | prospectively weighted covered units ÷ prospectively weighted total units | Weights blinded to eligibility, reliability, treatment, and audit outcome; always report unweighted coverage too |

Invalid without additional design are eligible relations divided by all sentences, raw edges divided by role outputs, checkpoint-generated candidates treated as naturally exhaustive, cluster-adjusted “effective sample size” without a sampling model, and any ratio whose numerator and denominator use different atomicity or identity rules.

## Relevant Hypotheses and Speculation

- **`C0006-EXP-01` — Nontrivial eligible core:** Hypothesis. It repeats the prospective small-core possibility already retained as `C0005-EXP-01`/`C0005-EXP-06`. There is no branch-local prevalence, coverage, role-relevance, or reliability result.
- **`C0006-EXP-02` — Reliable but trivial residue:** Hypothesis. It restates the accepted live coverage-failure and role-mismatch alternative in `C0005-INTG-09` and `C0005-ALT-01`. It is not a finding.
- **`C0006-EXP-03` — Denominator inflation:** Hypothesis about magnitude. The branch already rejects raw pair counts without fixed denominator, deduplication, and clustering, but contains no count showing that pair expansion is substantial in this handoff.
- **`C0006-EXP-04` — Factual-stratum concentration:** Hypothesis. It repeats the predeclared task/role-stratum possibility retained after C0005. A favorable factual stratum cannot be promoted after audit and cannot support claims about the full role.
- **`C0006-EXP-05` — Qualification-loss exclusion:** Hypothesis. It is consistent with the accepted requirement that qualification be preserved and with the coverage/role-mismatch alternative, but no branch-local exclusion composition is known.
- **`C0006-EXP-06` — Clustered sparsity:** Hypothesis. C0005 requires clustering to be reported, but the branch has no nominal or effective diversity estimate for sources, passages, claim families, outputs, tasks, or cycles.
- **`C0006-EXP-07` — Scalar gate instability:** Speculation. Accepted state already shows that one pooled reliability statistic and scalar completeness are insufficient. The stronger claim that a multidimensional gate is necessary for this exact decision remains untested because the decision target is not frozen.
- **`C0006-EXP-08` — Denominator observability limit:** Partly repeats accepted observational boundaries. Ordinary artifacts cannot expose a complete latent candidate-relation universe, and selected-subset reporting is checkpoint-created. The exact fields that can be recovered reliably without intervention remain untested.

These possibilities are not mutually exclusive. Nontrivial core size, factual-stratum concentration, qualification loss, cluster collapse, high reliability, and low role relevance can occur together and should be treated as a result profile rather than competing explanations that one statistic will resolve.

## Prior Contradictions or Objections

1. **No gate without a decision target.** `branches/B001/cycles/C0006/02_critic.md` objects that “nontrivial,” “central,” and “role relevant” are not falsifiable until the later experiment, supported claim, population, and unit of generalization are fixed. This is consistent with `C0005-INTG-10`, which says thresholds and failure actions must be tied to the intended next experiment.
2. **Causal dependence wording is prohibited.** The Explorer’s proposed share of final outputs that “depends on” eligible units contradicts `C0005-INTG-02`. Only observable relation-preserving incorporation, output-unit coverage, qualification preservation, and blinded role-function judgments are internally authorized endpoints.
3. **The proposed hierarchy is not a hierarchy.** Task instances, claims, evidence units, relation edges, groups, sections, downstream units, and clusters cross-cut one another. The Critic’s linked lattice correction follows accepted many-to-many and split/merge requirements in `C0005-INTG-04`.
4. **The full workload is not one denominator.** All role units, factual/assertive units, candidate relations, eligible relations, and output sections answer different questions. Treating all nonfactual work as direct-support failures creates mechanical low coverage; excluding it entirely conceals role mismatch.
5. **Candidate relations are not naturally exhaustive.** Writer-supplied, coder-proposed, bounded-set, and checkpoint-reported candidates are different universes. No internal record supports a denominator of all true or possible relations.
6. **Pair reduction can undercount legitimate multiplicity.** Multiple passages can provide complementary or independently sufficient support, and split claims can preserve real scope differences. Group counts must accompany, not replace, edge counts.
7. **Role relevance and importance can be circular.** Ratings made after eligibility, reliability, or treatment outcomes could favor the measurable residue. A prospective, blinded rubric with weighted and unweighted results is required; even then it remains judgment-based.
8. **Denominator and codebook cannot be frozen independently.** Counts depend on atomicity, identity, direct-support eligibility, evidence boundaries, split/merge rules, and many-to-many semantics. The current deliverable can map conceptual objects, but operational denominator rules must be co-developed with the minimal codebook on development data.
9. **Cluster-adjusted effective counts need an inferential target.** Source, passage, claim-family, output, and task clustering represent different dependence structures. Without a declared population and sampling model, none is a uniquely valid effective sample size.
10. **Established branch tensions remain active:** narrow reliability versus ecological validity; one-to-one tractability versus natural many-to-many evidence; strict versus relaxed boundaries; observability versus behavioral contamination; direct support versus qualification; agreement versus construct validity; and full-source access versus scalable resource cost. Provenance: `branches/B001/summaries/C0005_dense.md` and `C0005-INTG-04` through `C0005-INTG-10` in `branches/B001/state/current_state.md`.
